# Evaluation privacy

- Use synthetic fixtures and example identities, repositories, and issue links. Do not copy private conversations or records into evaluations.
- Keep reports about methods, observed behavior, and verification limits. Omit personal history, live user setup, account details, credentials, and temporary absolute paths.
- Preserve tested inputs, measured results, technical versions, and uncertainty. Remove private observations instead of presenting them as synthetic checks or inventing replacement evidence.
- Keep raw transcripts, host configuration, and installation backups outside the repository. Check evaluation changes for identifying context before publishing.
